Concepts

Algorithms and techniques that recur across problems.

  • Breadth-first search

    Visit every node one step from the start, then every node two steps away, and so on outward. A queue keeps the nodes in the order they were found, which makes breadth-first search the tool for fewest-step paths and level-by-level work.

    graphtreequeue

  • Depth-first search

    Follow one path as deep as it goes, then back up to the most recent branch not yet tried. A stack holds the branches still to try, and a visited set keeps cycles from looping forever.

    graphtreestackrecursion

Utilities

How language and library features behave.

  • How Python's zip pairs lists

    zip walks several lists in step, taking the item at the same position from each and yielding them together as a tuple. It stops as soon as the shortest list runs out, so the leftover items of longer lists are never read.

    pythoniteration
