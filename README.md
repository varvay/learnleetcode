# learnleetcode

A public journal of my programming study through LeetCode.

Every problem I work on gets its own page with:

- a link to the original problem
- the solution I wrote myself, including earlier attempts when they taught me something
- my notes: the approach, why it works, complexity, and the mistakes I made along the way

The goal isn't to collect answers. It's to keep a record of how my thinking develops, so I can come back to a pattern like sliding window or DP and see how I learned it.

📖 Browse the journal: https://varvay.github.io/learnleetcode/
